# Group 7 contribution guide

The IT2226 guidebook expects individual supervised-model work, GenAI work, version history and AI-use records. Confirm specific requirements with the tutor.

- Four members commit under **their own accounts**, in small increments.
- Branches such as `feat/member-dataset-audit` can keep parallel work separate; pull requests are optional and no CI is configured.
- Use `validate-local.bat` rather than GitHub Actions.
- Record each training run's data version, split, seed, configuration and metrics.
- Maintain personal AI-use logs based on `docs/AI_USE_LOG_TEMPLATE.md`.
- Make sure you can explain and edit the code you contribute.

Conventional Commit format: `<type>(<scope>): <concise summary>`.
